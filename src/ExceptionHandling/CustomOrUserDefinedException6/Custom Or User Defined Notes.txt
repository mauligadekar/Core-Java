How to Create Your Own User-defined Exception in Java?
Step 1: User-defined exceptions can be created simply by extending the Exception class.
        class OwnException extends Exception

step 2: if we dont want to store exception details define a default constructor.

Step 3: If we want to store exception details, define a parameterized constructor with string as a parameter,
        OwnException(String str)
        {
          super(str); // Call superclass exception constructor and store variable "str" in it.
        }

Step 4: we need to create an object of the user-defined exception class and throw it using throw clause.
        throw new OwnException("Exception details");
