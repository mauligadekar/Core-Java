Finally :
Finally block is always Executed whether the exception is occured or not.
use to maintain the clean-up code.

finally block is used to free up resources, cleaning up code, closing DB connection, io stream, etc

Java finally block is used to prevent resource leak.
the code is put inside the finally block to ensure that the resource is always recovered.

====== Conditions where Finally Block does not execute: ===========

When System.exit() method is invoked before executing finally block. JVM will shutdown here
When an exception happens in the finally block.

=> System.exit(0) dominate finally block
=> System.exit(0)
  0 => neans Normal Termination
  1 or any number => Abnormal Termination

=========== Difference Between Final vs Finally and Finalize ========
Final:

Final is a Access Modifiers Applicable for classes , method and variable
final class => we cannot extends
final method => we cannnot override
final variable => we cannot chenged its values

Finally :

it is block of code associated with the try catch.
inside the finally we cna take cleanup code or resource deallocation code
main purpose to maintian the cleanup code.
always executed whether exception occcured or not.

Finalize :

it is a method associated with the garbage collector.
GC will calll this method just before destroying the object.
purpose to perform the cleanup Activity.

what is cleanup in finally and finalize :
finally => to close the resource opend in the try block

finalize => to perform object related cleanup we should use finalize
